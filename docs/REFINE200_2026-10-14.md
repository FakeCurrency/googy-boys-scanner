# REFINE200 — 200 refinements and fixes (2026-10-14)

Owner ask (2026-10-14): *"Give me 200 things worth refining and fixing. Then just go
ahead and do it."*

Sources: four review passes (trade path, workflows/ops, website/API, evidence) gave
items 1–100; ten area finders (PhaseMap, lenses, scripts, Functions, chart, pages,
config, tests, engine/backtest, published data) gave items 101–200. Every item was
checked against the code or the committed data by the finder that reported it, and
again by the implementer before it was changed.

**Status key**
- **DO** — shipped in this batch (see the PR that names the item number).
- **OWNER** — changes which trades the bot takes, sizes or exits, or touches the
  PhaseMap spec. Not shipped: the hc4-1 cycle started a clean, hands-off sample on
  2026-10-14 ("I'm no longer going to close anything by hand"), and changing the
  rules under it would void the very test it exists to run. Each one is written up
  in `docs/DECISIONS_2026-10-14.md` with the replay evidence.
- **ACTION** — needs the owner to do something outside the repo (a secret, a
  Cloudflare setting).
- **SKIP** — recorded owner ruling, or the change would touch the closed track
  record.

Work packages (WP) are the units the fixes shipped in.
